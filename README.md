# grupFly
Projeto Gestao de viagens


Projeto de sistema de viagens desenvolvido com Java e Spring Boot.

## 📌 Sobre o projeto

O grupFly está em fase inicial de desenvolvimento e tem como objetivo simular funcionalidades presentes em plataformas de viagens e busca de voos.

Atualmente o projeto está focado na modelagem das entidades principais do sistema, utilizando conceitos de Programação Orientada a Objetos e Spring Data JPA.

---

## 🚀 Estrutura inicial

Modelos já criados:
- IdaEVolta
- Aeroporto
- Cidade
- ClasseVoo
- Estado
- Localidade
- País

---

## 🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- PostgresSQL
